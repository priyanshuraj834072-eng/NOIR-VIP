NOIR-VIP UPDATE PACKAGE

Included:
- index.html and admin.html (existing current HTML copies)
- api/purchase.js
- api/cron.js
- api/admin/settings.js
- vercel.json

IMPORTANT BEFORE PRODUCTION
1. Merge these files into the existing project; do not delete your other API files (especially api/_auth.js, wallet/history/referral/team/deposit/withdrawal APIs).
2. Set Vercel Environment Variables:
   - CRON_SECRET: a long random secret. The scheduled cron request must send Authorization: Bearer <same value>.
   - Keep your existing Firebase Admin environment variables and ADMIN_USERNAME / ADMIN_PASSWORD unchanged.
3. vercel.json schedules /api/cron at 13:30 UTC, which is 19:00 Asia/Kolkata daily.
4. Cron schedules run only after deployment to Vercel and only if the Vercel plan/project supports Cron Jobs. Check the project's Cron Jobs page/logs after deployment.
5. Test the cron endpoint manually in a non-production/staging environment first, using Authorization: Bearer <CRON_SECRET>. Never expose the secret in frontend code.
6. Do not enable real payouts until you have checked purchase records, wallet transactions, and idempotency in staging.
7. api/admin/settings.js uses x-admin-username and x-admin-password headers matching ADMIN_USERNAME and ADMIN_PASSWORD environment variables, consistent with the described existing setup. Confirm your admin frontend sends these headers.

CAUTION
This package is not a guarantee that the whole app is production-ready. Integrate with the current repository and test frontend/backend compatibility before production. The cron code credits dailyProfit from existing purchase records; confirm this payout rule matches your intended business logic before enabling it.
